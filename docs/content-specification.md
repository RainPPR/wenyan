# 高中文言实虚词汇总平台 - 内容编排要求与规范 (Content Specification)

本文档汇总了高中文言实虚词汇总平台在数据整理、义项解构、例句标注及检索展示方面的核心编排规范与经验总结，供开发者与 AI Agent 共同遵循。

---

## 1. 核心设计哲学与编排目标

1. **务实纯粹 (Pragmatic & Static)**
   - 平台定位为高中文言文词汇检索与学习静态工具，专注于字词查阅、完整义项、权威课文例句与白话译文。
   - 彻底剔除 AI 交互、在线刷题、生词本状态及营销噱头，保持极速、离线可用的纯净体验。

2. **数据严谨零占位 (Zero-Placeholder Guarantee)**
   - 全库词条及义项必须配备真实的高中语文必修/选择性必修课文（如《鸿门宴》《廉颇蔺相如列传》《过秦论》《师说》《劝学》《赤壁赋》等）或典籍原文。
   - **严格禁止**出现 `（无例句）`、`N/A`、`未知`、`暂无`、`无翻译` 等占位文本。每个例句必须具备 `text`（原文）、`source`（课文出处）、`translation`（白话译文）。

---

## 2. 义项独立解构规范 (Unmerged Sense Architecture)

在文言文词汇整理中，同一词语往往兼具多种词性与不同语义。为了保证学习者清晰理解与精准检索，数据编排遵循以下**解构规则**：

1. **单项词性与释义 (Single POS & Meaning Per Sense)**
   - **严禁混杂合并**：禁止在词性 (`pos`) 或核心释义 (`meaning`) 中出现斜杠 `/` 或多义项堆砌（如禁止 `形容词/动词`，或 `秤锤 / 权势 / 变通`）。
   - **拆解粒度**：每一个独立的词性（如 `名词`、`动词`、`形容词`、`副词`、`介词`、`通假字`、`固定短语` 等）及不同含义，均必须拆解为 `senses` 数组中独立的 `SenseItem` 对象。

2. **义项与例句一一对应**
   - 拆解后的每一个独立义项，均须精准绑定对应的课文例句。
   - 若某一字词有 5 个不同义项，则 `senses` 数组包含 5 个独立元素，各自具备专属例句、出处与译文。

---

## 3. 数据架构与模块化维护 (Data Architecture)

1. **模块化数据集划分**
   - 实词归入 `/src/data/shiciPart1.ts` ~ `shiciPart6.ts`（以 `RawVocabularyEntry[]` 导出）。
   - 虚词归入 `/src/data/xuci.ts`（以 `RawVocabularyEntry[]` 导出）。

2. **属性解耦与分类映射**
   - 数据源条目（`RawVocabularyEntry`）**不硬编码** `category` 或 `categoryLabel`。
   - 由 `/src/data/allVocabulary.ts` 在加载时统一映射注入 `category: 'shici' | 'xuci'` 与 `categoryLabel: '文言实词' | '文言虚词'`。

3. **唯一标识符 (Unique ID)**
   - 每一个词条拥有严格唯一的 `id`（如 `quan`、`xian_guan`、`wei_place`），杜绝 React Key 重复碰撞。

---

## 4. 多阶梯相关度检索规范 (Multi-Tier Relevance Search)

检索算法需满足高中文言文查阅的实际心理，采用多阶梯权重排序：

1. **第一阶梯（权重 100）**：汉字字词精确完全匹配（如搜索 "望"，词条 "望" 置顶）。
2. **第二阶梯（权重 80）**：字词前缀匹配（如搜索 "词"，匹配 "词采"）。
3. **第三阶梯（权重 60）**：字词子串包含匹配。
4. **第四阶梯（权重 50）**：无声调拼音完全匹配或前缀匹配。
5. **第五阶梯（权重 30）**：核心释义或词性包含匹配。
6. **第六阶梯（权重 10）**：课文例句原文或出处包含匹配。

---

## 5. UI/UX 细节与交互规范

1. **Modal 滚动锁与布局补偿**
   - 弹窗打开时设置 `document.body.style.overflow = 'hidden'`。
   - 同时计算 `window.innerWidth - document.documentElement.clientWidth` 计算滚动条宽度，并为 `body` 施加 `paddingRight` 补偿，防止页面横向抖动。

2. **响应式卡片与高清字形**
   - 采用 Tailwind CSS v4 现代化样式，搭配衬线/无衬线体混合排版，确保文言文例句与白话译文对比清晰流畅。
