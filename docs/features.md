# 核心功能模块 (Core Features)

1. **字词检索与分类列表 (Vocabulary Directory & Search)**
   - 支持拼音、汉字、释义、例句与课文出处实时模糊检索。
   - 分类筛选：常见实词、核心虚词、高频难词与固定结构。
   - 支持一键筛选高频重点字词。

2. **词条详情模态框 (Detailed Word Modal)**
   - 显示多音多义项、词性划分与词类活用。
   - 展现高中经典课文例句与准确汉语翻译对照。
   - 标注常见语法特征与使用提示。

3. **AI 句法赏析与文言助研 (AI Sentence Analyzer)**
   - 基于 Gemini API，支持对任意文言例句进行句法结构、字词释义及语法特点剖析。
   - 支持在词条详情或列表中点击例句一键跳转 AI 赏析。
