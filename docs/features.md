# 核心功能模块 (Core Features)

1. **多维加权智能检索与分类列表 (Vocabulary Directory & Smart Search)**
   - **智能权重排序算法**：针对文言检索场景深度的加权衡量算法：
     1. **字词精准完全匹配**（权重 10,000分）：如搜索“望”，精准匹配字词“望”置顶呈现。
     2. **字词前缀与包含匹配**（权重 7,500 / 5,000分）：前缀词（如“望洋兴叹”）与包含词（如“名望”）。
     3. **拼音与无声调拼音匹配**（权重 4,500 ~ 2,500分）：支持带调或去调拼音（如搜索 `wang` 匹配 `wàng`）。
     4. **义项释义与词性匹配**（权重 3,000 ~ 1,400分）：词性（通假、副词等）与释义文本。
     5. **课文出处与例句对译匹配**（权重 1,300 ~ 400分）：出处标题（如搜索《鸿门宴》）、原文例句与现代汉语译文。
     6. **短词优先与高频附加加权**：针对单字检索场景自动计算字数紧凑度与高频标记加权。
   - **分类切分**：提供全部汇总、文言实词、文言虚词三大快速切分选项。
   - **高频筛选**：支持一键切换“只看高频重点字词”，聚焦高考高频考点。

2. **无缝体验词条详解模态框 (Detailed Word Modal)**
   - **防抖防移位滚动锁**：打开模态框时自动锁定背景 `document.body` 滚动，并动态计算计算滚动条宽度做 `paddingRight` 补正，彻底解决背景移位与双滚动条显示问题。
   - 采用古典宣纸风排版与高质感衬线字体，提升文言文古朴沉浸阅读体验。
   - 显示多音多义项、词性划分与词类活用说明。
   - 展现高中必修与选择性必修经典课文例句与准确汉语翻译对照（如《鸿门宴》《廉颇蔺相如列传》《过秦论》《师说》《劝学》《赤壁赋》等）。
   - 标注常见语法特征、通假异读与考点探微警示。
   - 支持点击背景遮罩、右上角关闭按钮或按 `Esc` 键一键快捷退出模态框。

3. **静态打包与 GitHub Actions 自动化 (Static Build & GitHub Actions)**
   - 彻底移除服务端与 API 依赖，打包产物均为纯静态 HTML/CSS/JS 文件。
   - 借助 GitHub Actions CI 工作流 (`ci.yml`) 实现 PR 与主分支推送时的类型检查与代码风格严格校验。
   - 借助 GitHub Actions 部署工作流 (`deploy.yml`) 实现推送主分支即自动打包与部署发布至 GitHub Pages。
