# 核心功能模块 (Core Features)

1. **字词检索与分类列表 (Vocabulary Directory & Search)**
   - 支持拼音、汉字、释义、例句与课文出处实时模糊检索。
   - 分类切分：提供全部汇总、文言实词、文言虚词三大快速切分选项。
   - 高频筛选：支持一键切换“只看高频重点字词”，聚焦高考高频考点。

2. **词条详解模态框 (Detailed Word Modal)**
   - 采用古典宣纸风排版与高质感衬线字体，提升文言文古朴沉浸阅读体验。
   - 显示多音多义项、词性划分与词类活用说明。
   - 展现高中必修与选择性必修经典课文例句与准确汉语翻译对照（如《鸿门宴》《廉颇蔺相如列传》《过秦论》《师说》《劝学》《赤壁赋》等）。
   - 标注常见语法特征、通假异读与考点探微警示。
   - 支持点击背景模糊遮罩或右上角关闭按钮一键快捷退出模态框。

3. **静态打包与 GitHub Actions 自动化 (Static Build & GitHub Actions)**
   - 彻底移除服务端与 API 依赖，打包产物均为纯静态 HTML/CSS/JS 文件。
   - 借助 GitHub Actions CI 工作流 (`ci.yml`) 实现 PR 与主分支推送时的类型检查与代码风格严格校验。
   - 借助 GitHub Actions 部署工作流 (`deploy.yml`) 实现推送主分支即自动打包与部署发布至 GitHub Pages。
